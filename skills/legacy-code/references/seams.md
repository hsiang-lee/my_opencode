# 遗留代码 — 接缝、change point 与特征测试

回到索引: [../SKILL.md](../SKILL.md)

> 遗留代码的定义、核心原则与节奏以 `../SKILL.md` 为准；本文件只写接缝、change point、effect sketch 与特征测试。

## 1. 三个基础概念

| 概念 | 含义 |
|------|------|
| **接缝 Seam** | 不改动原位置就能改变行为的地方 |
| **特征测试 Characterization Test** | 不测「应该是什么」，只锁定「现在实际是什么」 |
| **依赖 Dependency** | 阻止隔离测试的障碍（硬编码、全局状态、内部 new、静态调用、环境读取） |

## 2. change point / test point / effect sketch

**change point**：本次要改的那一行/那个函数。一次只认领一个，多认领的逐个排队。
**test point**：能观察到该 change point 行为的最近位置（优先公共入口）；找不到 → 先做接缝，别硬测私有细节。
**effect sketch**：从 change point 向上追出全部受影响的调用方与外部契约（谁调用、传什么、依赖什么副作用），只用于风险评估；实际覆盖边界 = 即将改动的路径 + 直接调用者。

## 3. 接缝三类型

| 类型 | 机制 | 本项目形态 | 优先级 |
|------|------|------------|--------|
| 对象接缝 | 多态 / 接口替换实现 | 虚函数 + 构造注入 | 首选 |
| 链接接缝 | 换链接库改变行为 | 测试链接替身实现 | 次选 |
| 预处理接缝 | 宏 / 条件编译 | `#ifdef` / `-D` | 最后手段 |

优先对象接缝的理由：类型安全、编译期可查、不污染生产代码；预处理接缝会把测试关切写进产品源码。

## 4. 安全修改五步

```
1. 识别修改点 → 列出它触达的全部依赖
2. 找接缝   → 在修改点附近找可插入测试的位置（按三类型优先级）
3. 解依赖   → 用 dependency-breaking.md 的技术，一次解一个
4. 写特征测试 → 锁定当前行为（包括看起来错误的行为）
5. 小步修改 → 每步跑全部测试，绿了再下一步
```

**顺序不可颠倒**：先改代码再找测试 = 没有安全网的高空作业。

## 5. 特征测试

### 何时写

- 修改前，目标代码没有现成测试
- 重构前，需要安全网
- 修 bug 前，先锁住「现在错在哪」

### 五步

1. 定目标方法（从最稳定的公共入口开始）
2. 构造最简单的输入（典型值 + 边界值：null / 空集合 / 0 / 最大值）
3. 调用，记录实际返回值 / 副作用
4. 把记录值写成断言
5. 命名 `locks_current_<行为描述>`

### 真实依赖还是替身

写特征测试时先问两件事，答案决定用真实依赖还是替身：

| 判据 | 用真实依赖 | 用替身 |
|------|------------|--------|
| 速度 | 单次调用在测试可接受范围内 | 依赖慢（网络 / DB / 文件系统） |
| 副作用 | 无持久化、无外部状态变更 | 会写外部系统或污染共享状态 |
| 确定性 | 输出稳定、可重复 | 依赖时钟 / 随机 / 环境 |
| 契约覆盖 | 需要锁定真实交互行为 | 只需观察调用与返回值 |

默认**优先真实依赖**：替身会掩盖真实契约差异。选替身时，替身只模拟被观察的接缝，不复制生产逻辑；接缝选错导致的脆弱测试，先修接缝而不是加更多断言。

### 三条陷阱

| 陷阱 | 应对 |
|------|------|
| 断言值来自实际运行，不代表正确 | 只当安全网，不当规格；发现疑点另开 bug 记录 |
| 特征测试失败可能是测试写错 | 先怀疑测试，再怀疑代码 |
| 不理解新行为前删除旧特征测试 | 新行为有测试覆盖后才可删 |

### 覆盖策略

不要试图一次覆盖全部路径。先覆盖**即将修改的那条路径** + 它的直接调用者；其余分支暂不覆盖。

## 6. 常见陷阱汇总

| 陷阱 | 后果 | 应对 |
|------|------|------|
| 边解依赖边改行为 | 失败后无法定位是结构还是语义 | 两次提交，先结构后语义 |
| 一次解多个依赖 | 同上 | 一次一个 |
| 只覆盖快乐路径 | 改动后边界崩了不知道 | 补 null / 空 / 边界 |
| 用 `#ifdef TEST` 开路 | 产品代码被测试污染 | 优先对象接缝 |
| 特征测试写完就删 | 失去回归保护 | 保留直到新行为有测试 |
